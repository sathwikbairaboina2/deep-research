# ADR-0004: v0.1 includes the supervisor fan-out and resume; it excludes JS rendering, PDF page cites and an LLM judge

- Status: accepted (2026-10-04)

## Context
The design put the supervisor, `Send` fan-out, checkpoints and evals in v0.2. The board pitch and the "proves" line (LangGraph subgraphs, Send fan-out, evals) need them in the first shipped version.

## Decision
- In: planner, supervisor with `Send`, researcher subgraph, verifier, coverage gate, writer with linter, budget, page store, `SqliteSaver` with `dr resume`, `dr eval`, `dr bench`, and a minimal `dr serve`.
- Prototype (2026-10-04, langgraph 1.2.12): 8 topics x 2 rounds through a compiled subgraph node with `max_concurrency=3` merged 16 claims with a peak of 3 concurrent researchers. A crash in one of 4 parallel branches resumed with `invoke(None, config)` and re-ran only the failed branch (4 calls before, 5 after).
- Out: headless browser, PDF page offsets, a quote-supports-claim LLM judge, hosted providers, a demo GIF.

## What I gave up
- The "supports the claim" metric from the design. v0.1 reports the rejection rate and the shipped-unverifiable count only.
- A GIF. The README shows real CLI output instead, which is honest and cheap to regenerate.
